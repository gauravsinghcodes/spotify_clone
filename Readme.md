# 🎧 Spotify Clone

A fully responsive and interactive **Spotify-inspired music player** built using **HTML, CSS, and JavaScript**.  
Features playlists, a sticky playbar like Spotify, audio controls, a sidebar, and a clean UI.

🔗 **Live Demo:** *(https://spotify-clone-kappa-rouge.vercel.app/)*  


---

## 🚀 Features

### 🎵 Multiple Playlists
- Bang Bang  
- Mohabbatein  
- Holiday  
- KGF  
- Main Tera Hero  

(Playlists are loaded dynamically using JavaScript.)

### 🎛️ Music Player Controls
- Play / Pause  
- Next / Previous  
- Dynamic time update  
- Seekbar scrubbing  
- Auto-next track  
- Volume control + mute  
- Sticky playbar (stops at footer like real Spotify)

### 🧭 Navigation & Layout
- Sidebar (collapsible on mobile)
- Responsive card layout
- Scrollable playlist section
- Custom scrollbars
- Spotify-style footer with social icons

## 🚀 Deployment Guide (Vercel)

1. Go to **https://vercel.com**
2. Click **"New Project"**
3. Import your **GitHub repository**
4. Select:
   - **Framework:** Other  
   - **Build Command:** *leave empty*  
   - **Output Directory:** `.`  
5. Click **Deploy**

Vercel will host all HTML, CSS, JS, images, and MP3 files automatically.
